# Dungeon Run

A browser-based, turn-based hero strategy game. Explore grid-based dungeons, defeat bosses to learn their spells and weapon abilities, gather equipment, and customize a hero through damage, defense, and utility talent trees.

## Design direction

Each turn grants a class-specific movement allowance and two action points. Basic attacks and abilities cost action points; spells additionally cost mana. This keeps positioning useful and makes turns predictable without a random card hand.

Choose a starting class preset, earn experience and talent points, return to town to spend gold, and seek powerful mystery merchants in deeper dungeon floors. Bosses offer a choice from their spell pool and the strongest equipment.

## Project goals

- A static web app compatible with GitHub Pages.
- Local autosaves and JSON progress export/import.
- No backend required.
